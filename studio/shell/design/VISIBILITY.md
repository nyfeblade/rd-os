# Visibility law (Luke)

**Only necessary information should be visible.**

Show by default:
- Current conversation (who + thread + composer)
- What needs the human now (gates)
- Connector problems only (e.g. needs sign-in)
- Way to open Code

Hide until needed:
- Full seat roster / rooms list
- Full connectors catalog (P0/P1)
- Idle CA map / disconnected watches
- Mode parade
- Eng taxonomy the stranger doesn’t need

Code remains on demand. Chat | Board default.
